# Needle Aspiration versus Tube Thoracostomy — Symptom-Led Management of Spontaneous Pneumothorax

An interactive, referenced walkthrough of the symptom-led decision algorithm for spontaneous
pneumothorax — tension/haemodynamic-instability screening, a high-risk-feature screen (SSP,
bilateral disease, haemopneumothorax, hypoxia, age/smoking, positive-pressure ventilation),
a symptom-led fork into conservative care or needle aspiration, a repeat-aspiration
reassessment loop (maximum of two attempts), ambulatory or standard small-bore drainage,
a 48-hour persistent-air-leak escalation checkpoint, and definitive recurrence prevention.
Every box in the diagram can be selected to reveal, in one place: what the step means, why
the algorithm calls for it, and the sources behind it.

**Live site:** https://satbuhan.github.io/spontaneous-pneumothorax-protocol/

## Why this exists

A flowchart alone tells a reader *what* to do at each step but not *why* — and the choice
between needle aspiration and tube thoracostomy for spontaneous pneumothorax has stayed
contested for over two decades, with real evidence showing the two approaches trade off
immediate procedural reliability against length of stay, admission burden and adverse
events, rather than one simply being "better." This page keeps the original algorithm
exactly as authored, and attaches the clinical reasoning, the effect sizes behind each step,
and the literature to each box without cluttering the diagram itself.

The algorithm this page presents is Figure 1 ("Symptom-led algorithm for the management of
spontaneous pneumothorax") of "Tube Thoracostomy Versus Needle Aspiration in the Management
of Spontaneous Pneumothorax: A Systematic Review of Evidence from 2000's" — an unpublished
manuscript (2026, single/blinded authorship as declared in the manuscript itself), a PRISMA
2020 systematic review (PubMed/MEDLINE, 1 January 2000 to 31 July 2026; 7 head-to-head RCTs
contributing more than 850 randomised participants per the review's own Table 2/Graphical
Abstract tally, plus 2 landmark strategy RCTs and several evidence syntheses; 80 references)
— from standalone Figure 1 and Graphical Abstract `.docx` files supplied directly by the
authors alongside the manuscript.

## Status

This is a working version, built to be tested on both desktop and mobile.

- **Source workflow:** the manuscript's own narrative text, tables and 80-entry bibliography
  were condensed as usual by an external AI (Gemini) using this project's structured
  condensation prompt. Figure 1 and the Graphical Abstract were each supplied as separate
  `.docx` files alongside that condensation; this build read both images directly (the
  Graphical Abstract's embedded image was a high-resolution TIFF, converted for viewing) to
  confirm the condensation's box-by-box transcription against the actual figures rather than
  trusting the extraction text alone.
- **Reference verification — explicit, author-granted exception (the sixth in this atlas):**
  asked directly whether to extend the same no-independent-re-verification policy used for
  `epinephrine-revisited-protocol`, `ketamine-indications-protocol`,
  `haloperidol-adjunct-protocol`, `geriatric-pain-protocol` and
  `metoclopramide-ondansetron-protocol` to this tool's 80-entry bibliography, the author
  confirmed the same policy again. The reference list was **not** independently re-verified
  against primary sources; every entry's `kind` field says so plainly. See
  `assets/content.js`'s header comment and `METHODOLOGY.md` for the full precedent record.
- **Figure-vs-text discrepancies, disclosed rather than silently resolved:** the manuscript's
  own narrative repeatedly presents "needle aspiration or ambulatory small-bore drainage" as
  parallel first-line options, while Figure 1 places ambulatory drainage strictly *after* a
  failed (and possibly repeated) aspiration attempt. A number of granular figure details —
  cannula gauge and insertion sites, the 2.5 L aspiration ceiling, French-gauge ranges, review
  intervals, the 24-hour drain-removal rule — appear only in the figure and are never
  discussed in the manuscript prose. Each is flagged in its own node's "Cautions & special
  populations" section rather than silently backed with a citation that was never there.
- **A genuinely new rendering feature — a real feedback loop:** this is the first tool in the
  atlas whose source figure draws an actual backward edge — a dashed arrow, labelled
  "Reassess" in the figure's own caption, from the second-aspiration-attempt box back up to
  the re-expansion decision one row above it. Every earlier tool's "reassess" step was a
  forward-only box; this one is a real loop a reader can repeat. See `METHODOLOGY.md` for how
  `app.js` renders it (a dedicated `"loop"` edge variant, not the existing `DETOUR` mechanism).
- **Honest gaps, not invented citations:** the drain-removal box ("Remove drain after 24 h
  without air leak · Confirm on imaging · Discharge") carries **no references at all** — this
  entire step's protocol is not discussed anywhere in the manuscript prose, only drawn in the
  figure, and its "Cautions" section says so plainly rather than attaching a citation that
  doesn't actually support it.

## Disclaimer

This is an academic / educational reference tool, not a substitute for institutional protocol
or bedside clinical judgement. Doses and thresholds shown reflect the algorithm as authored;
verify against current local protocol before clinical use. This tool's reference list is
reproduced directly from the source manuscript's own bibliography and was not independently
re-verified for this build — see Status above.

## How it's built

Plain HTML/CSS/JS, no build step and no framework — a single static site that GitHub Pages
can serve directly.

```
index.html          page structure — masthead, the diagram (entry, tension/instability
                     screen, high-risk screen, symptom-led fork, aspiration with its
                     reassessment loop, drainage, air-leak escalation, recurrence
                     prevention), readout panel, references, abbreviation legend, footer
assets/style.css     design (the "paper" masthead/references, the diagram's trunk-with-
                     branches grid, the new dashed feedback-loop edge style)
assets/content.js    ← single source of truth for every node's text and reference list. Edit
                     this file to change what the page says.
assets/app.js        rendering + interaction (builds the diagram and its connector lines from
                     content.js, handles the click-to-expand panel on desktop and the bottom
                     sheet on mobile)
```

### Running it locally

No install needed:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

### Editing content

Open `assets/content.js`. Each entry in `NODES` is one box from the diagram (`meaning`,
`rationale`, optional `dose`/`cautions`, and `refs` pointing at numbered entries in
`REFERENCES`). Add or edit a reference in `REFERENCES` and point to it by `id` from any node.
Never change a node's `label` or `sub` text without the author team's sign-off — those fields
are the algorithm itself, transcribed verbatim from the authors' own figure.
